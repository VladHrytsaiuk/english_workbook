# Passive Voice

Use the passive when **the action is more important than who did it**, or when the doer is unknown or obvious.

*The window **was broken** last night.* (we don't know who broke it)

## How to form it

**Object → subject**, then **be** in the same tense as the active verb + **V3**.

| Step | Example |
|---|---|
| 1. Active sentence | Shakespeare **wrote** *Hamlet*. |
| 2. Object becomes the subject | *Hamlet* … |
| 3. `be` in the same tense (Past Simple → was) | *Hamlet* **was** … |
| 4. Add V3 | *Hamlet* **was written** … |
| 5. Optional: `by` + doer | *Hamlet* was written **by Shakespeare**. |

## Modal verbs

`modal + be + V3`

- You **must finish** the report. → The report **must be finished**.
- They **can solve** the problem. → The problem **can be solved**.

## Tips

- Only **transitive** verbs (verbs with an object) can be passive: ~~*He was arrived.*~~
- Use `by` only when the doer is important or new information.
- Questions: **Was** the bridge **built** in 1990? **When was** the bridge **built**?
